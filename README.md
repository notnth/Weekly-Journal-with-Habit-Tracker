# Weekly-Journal-with-Habit-Tracker

A digital weekly journal inspired by Hobonichi with a habit tracker and to-do list.

Youtube Link: https://www.youtube.com/watch?v=E6j6w3XaUMc

## Purpose
The app helps user's journal and track their habits and to-do's weekly, laid out like a planner.

## Features
- Habit tracker from Mon to Sun with tick boxes.
- Pause and stop habits without losing past ticks, and resume them later.
- Weekly notes
- Weekly to-do list
- Navigation to other years and weeks
- Home page with personalized welcome
- Data is saved in browser

## Technologies
HTML, CSS, JS made with Claude

## How to run
Download or clone the repository and open index.html in browser.

## Project structure
- `index.html`: page structure
- `style.css`: styling
- `script.js`: app logic and data storage
